# homebrew-cloakview

Homebrew tap for [CloakView](https://getcloakview.com/) — a macOS meeting copilot that listens to your call, transcribes it live and shows suggested answers in an overlay that stays out of the window you share.

## Install

```sh
brew install --cask baphomet444/cloakview/cloakview
```

Apple Silicon, macOS 14.2 or later.

## Upgrade

```sh
brew upgrade --cask cloakview
```

The app is free; CloakView Pro is a one-time $99 upgrade.
